# Backup retention, earlier rule

Valid from 2024-02-01 to 2026-01-31

Nightly snapshots were kept for ninety days and then destroyed automatically. Anything needed beyond that had to be copied out by hand into a separate archive bucket before the ninetieth day. Superseded: this rule no longer governs and is kept only so old restore tickets still make sense.
